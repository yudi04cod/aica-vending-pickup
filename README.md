One pickup line, spoken by a vending machine to a passing human — for the
[One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee)
on make.fun.

`main.py` (Python standard library only) writes the single line to
`/output/entry.txt`, after validating it: 1–200 characters, one line, not blank.

> I've got forty snacks, exact change, and one coil that only jams for the cute ones — go ahead, press my buttons and see what drops.

Run it:

```sh
python3 main.py
```
